よくある質問

PNG の隣にできる「<名前>.nanodot」は何ですか？
そのシートの設定（セルの大きさ・スナップ・パレット・アニメ・マップ・注釈）です。絵そのものは素の PNG に保存し、設定は同じフォルダーの <名前>.nanodot（中身は JSON）に保存します。PNG を移したり名前を変えたりするときは、このファイルも同じ名前で一緒に動かしてください。なくても PNG は開けますが、設定は初めの状態になります。
Mac App Store 版で、PNG の隣にほかのファイルを書けますか？
Mac App Store 版は App Sandbox の中で動くので、PNG の隣で読み書きできるのは <名前>.nanodot だけです。アニメやゲームエンジン用データは、書き出すときにパネルで保存先を選びます。PNG と同じフォルダーを選べば、隣に書き出せます。
以前の版の「<名前>.nanodot.json」は使えますか？
使えます。GitHub からダウンロードした版は、<名前>.nanodot がなければ古い <名前>.nanodot.json を自動で読みます。Mac App Store 版は自動では読めないので、PNG を開いてから「ファイル ＞ 設定を読み込む...」で古いファイルを選んでください。どちらの版も、保存すると <名前>.nanodot に書きます。古いファイルは消しません。
ゲームエンジンで使うデータは、どう書き出しますか？
「ファイル ＞ ゲームエンジン用データを書き出す...」でフォルダーを選ぶと、<名前>.atlas.json（アニメと名前付きセルのフレーム。Aseprite / TexturePacker 互換）と、マップごとの <名前>.<マップ名>.tmj（Tiled 形式）を書き出します。PNG と同じフォルダーに置くと、そのまま読めます。保存のたびには書き出しません。⌘E で、前回の書き出し先にもう一度書き出せます。
Mac App Store 版に MCP サーバーの設定がありません。
MCP サーバーは GitHub からダウンロードした版だけの機能です。Mac App Store 版には入っていません。

FAQ

What is the “<name>.nanodot” file next to my PNG?
It holds the settings of that sheet: cell size, snap, palette, animations, maps and annotations. The artwork itself is saved as a plain PNG, and the settings go into <name>.nanodot (JSON) in the same folder. When you move or rename the PNG, move this file along with it under the same name. The PNG still opens without it, but the settings start from their defaults.
Can the Mac App Store version write other files next to my PNG?
The Mac App Store version runs inside the App Sandbox, so the only file it can read and write next to the PNG is <name>.nanodot. For animations and game engine data, you choose the destination in a panel when you export. Choose the PNG’s folder to put them next to it.
Can I still use “<name>.nanodot.json” from earlier versions?
Yes. The version downloaded from GitHub reads the older <name>.nanodot.json automatically when there is no <name>.nanodot. The Mac App Store version cannot read it automatically, so open the PNG and then choose File › Import Settings… and select the older file. Either version writes <name>.nanodot when you save. The older file is not deleted.
How do I export data for a game engine?
Choose File › Export Game Engine Data… and pick a folder. The app writes <name>.atlas.json (frames for animations and named cells, compatible with Aseprite / TexturePacker) and one <name>.<map name>.tmj per map (Tiled format). Put them in the same folder as the PNG and they can be loaded as is. They are not written every time you save. Press ⌘E to export again to the last folder.
The Mac App Store version has no MCP server setting.
The MCP server is available only in the version downloaded from GitHub. The Mac App Store version does not include it.
