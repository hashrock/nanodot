nanodot GitHub ↗

A sprite sheet editor for Mac.

シートの上で、
ドットを打つ。

歩行グラフィックやマップチップのような、小さな絵が並んだシートのためのドット絵ツール。
DotPainter ALFAR の操作感を手本に、いまのMacに合わせて作りました。

01 / STOCK ⇄ MAIN

見渡して、描く。

右のストックでセルを選び、
左のメインで拡大して描く。
入れ替えも、コピーも、マウスだけで。

02 / RIGHT BUTTON

右ボタンで、拾う。

右クリックでスポイト。
右ドラッグでコピーして、
そのままスタンプで押していく。

03 / FLIPBOOK

描きながら、動かす。

アニメは描いた先から再生。
前後のコマをオニオンスキンで重ねて、
GIF・APNG・連番PNGで書き出せます。

04 / MAP

並べて、試す。

描いたチップをその場でマップに仮組み。
レイヤーを重ねて、
つなぎ目や見え方を確かめられます。

05 / ANNOTATION

セルに、意味を。

セルごとに名前・通行可否・重なり順。
シートの横に置くJSONに保存するので、
ゲーム側からそのまま読めます。

06 / TEXT

文字も、ドットで。

フォントと大きさを選んで、
にじまないドットの文字を置けます。
日本語も、改行も。

07 / MCP

AIと一緒に描く。

nanodot は MCP サーバーを内蔵しています。
Claude Code などのエージェントが、シートを見ながら
描いたり、色違いを作ったり、マップを組んだり。
このMacの中だけで待ち受けます。

MCP の使い方とツール一覧

1. ⚙ の設定で「MCP サーバー」をオン

2. エージェントに登録

claude mcp add --transport http \
  nanodot http://127.0.0.1:47621/mcp
