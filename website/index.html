A sprite sheet editor for Mac.

シートの上で、
ドットを打つ。

歩行グラフィックやマップチップのような、小さな絵が並んだシートのためのドット絵ツール。
DotPainter ALFAR の操作感を手本に、いまのMacに合わせて作りました。

ソースからビルド

macOS 14 以降 · Xcode 16 以降

01 / STOCK ⇄ MAIN

見渡して、描く。

右のストックでセルを選び、
左のメインで拡大して描く。
入れ替えも、コピーも、マウスだけで。

02 / RIGHT BUTTON

右ボタンで、拾う。

右クリックでスポイト。
右ドラッグでコピーして、
そのままスタンプで押していく。

03 / FLIPBOOK

描きながら、動かす。

アニメは描いた先から再生。
並びを指定する簡易アニメと、コマを登録する登録アニメ。
GIF・APNG・連番PNGで書き出せます。
