プライバシーポリシー

最終更新日: 2026年11月11日

nanodot（以下「本アプリ」）は、あなたの情報を集めません。本アプリには利用状況の計測・広告・トラッキング・アカウントの仕組みがなく、インターネットにも接続しません。

集める情報

ありません。本アプリは、あなたの個人情報や利用状況を、開発者を含むだれにも送りません。

Mac の中で扱うもの

本アプリは次のものを、あなたの Mac の中だけで扱います。どれも外部へは送りません。

画像（書類）
あなたが開いた画像を読み、あなたが選んだ場所に PNG で保存します。
シートの設定（<名前>.nanodot）
セルの大きさ・パレット・アニメ・マップ・注釈などを、PNG と同じフォルダーの <名前>.nanodot に保存します。中身は絵についての設定だけで、あなたの名前やファイルの場所は入りません。
書き出したファイル
アニメ（GIF・APNG・連番 PNG）とゲームエンジン用データ（.atlas.json・.tmj）を、あなたが選んだ場所に書き出します。
クリップボード
コピーした範囲を macOS のクリップボードに画像として置き、貼り付けるときにクリップボードの画像を読みます。
設定
表示の切り替え、ウィンドウの配置、ゲームエンジン用データの前回の書き出し先（シートのファイルの場所と、そのフォルダーをもう一度開くための macOS のブックマーク）などを、macOS の設定の仕組みでこの Mac に保存します。

Mac App Store 版は App Sandbox の中で動き、あなたが開く・保存のパネルで選んだファイルやフォルダーと、その PNG の隣の <名前>.nanodot にだけ触れます。ネットワークを使う権限は持っていません。

MCP サーバー（直接配布版のみ）

GitHub で配布している版には、AI エージェントから本アプリを操作するための MCP サーバーが入っています。初めは無効で、設定で有効にしたときだけ動きます。この Mac の中（127.0.0.1）からの接続だけを受け付け、本アプリの側から外部へ接続することはありません。Mac App Store 版にはこの機能が入っていません。

クラッシュ情報

「システム設定 ＞ プライバシーとセキュリティ ＞ 解析と改善」で「App デベロッパと共有」を有効にしている場合、本アプリが異常終了したときの情報が Apple を通じて開発者に届くことがあります。これは Apple が提供する仕組みで、その扱いは Apple のプライバシーポリシーに従います。

このポリシーの変更

内容を変えるときは、このページを更新して最終更新日を改めます。

問い合わせ

Privacy Policy

Last updated: November 11, 2026

nanodot (“the app”) does not collect your information. The app has no analytics, advertising, tracking or accounts, and it does not connect to the internet.

Information we collect

None. The app does not send your personal information or usage data to anyone, including the developer.

What stays on your Mac

The app handles the following only on your Mac. None of it is sent anywhere.

Images (documents)
The app reads the images you open and saves PNG files to the location you choose.
Sheet settings (<name>.nanodot)
Cell size, palette, animations, maps, annotations and similar settings are saved as <name>.nanodot in the same folder as the PNG. It contains only settings about the artwork, not your name or file locations.
Exported files
Animations (GIF, APNG, PNG sequence) and game engine data (.atlas.json, .tmj) are written to the location you choose.
Clipboard
The area you copy is placed on the macOS clipboard as an image, and the app reads an image from the clipboard when you paste.
Settings
View options, window layout, the last folder you exported game engine data to (the location of the sheet file and a macOS bookmark that lets the app open that folder again) and similar settings are stored on this Mac with the standard macOS preferences system.

The Mac App Store version runs inside the App Sandbox. It can touch only the files and folders you choose in open and save panels, plus the <name>.nanodot file next to that PNG. It has no permission to use the network.

MCP server (direct download version only)

The version distributed on GitHub includes an MCP server that lets AI agents operate the app. It is off by default and runs only while you turn it on in the settings. It accepts connections only from this Mac (127.0.0.1), and the app never connects out to anything. The Mac App Store version does not include this feature.

Crash reports

If “Share with app developers” is turned on in System Settings › Privacy & Security › Analytics & Improvements, information about crashes of the app may be delivered to the developer through Apple. This is provided by Apple and is governed by Apple’s privacy policy.

Changes to this policy

If this policy changes, this page will be updated along with the date above.
