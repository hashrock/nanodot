# 画像

README やサイト、紹介記事などで使える画像です。スクリーンショットのスプライトは、すべてサンプルとして生成したものです。

| ファイル | 内容 |
|---|---|
| `logo.svg` | ロゴ（`Resources/AppIcon.svg` と同じ。黒一色） |
| `app-icon.png` | アプリアイコン（512×512、白い角丸の上にロゴ） |
| `screenshot.png` | メイン画面（1280×860） |
| `anim.png` | アニメウィンドウとオニオンスキン |
| `map.png` | マップの仮組み |
| `text.png` | テキストツール |
| `palette.png` | カラーピッカーとパレット |

サイト（`website/assets/`）にも同じスクリーンショットを置いています。撮り直したときは両方を更新してください。
